## Windows アプリ · v0.2.0

[Windows x64 インストーラー・ZIP をダウンロード](https://github.com/jeffrog-256k1/billing-memo/releases/latest) · [デスクトップガイド](docs/DESKTOP.md)

Web・デスクトップ版ともに**ダッシュボード、サービス管理、支払い予定、期間分析**に分かれています。開始日と終了日（両端を含む）で合計、月別金額、月平均を確認し、プロジェクトや分類で絞り込めます。**実際の支払い**は記録した支払日で、**予定請求**は予定日で支払済み記録と未払い見積もりを集計します。明細・月別合計を CSV 出力できます。為替レート未入力時は部分合計と表示します。最大 120 暦月で、平均には空の月や一部の日付のみの月も含まれます。

Windows 10/11 x64 用。EXE でインストールするか、ZIP 全体を展開して Billing Memo.exe を起動します。オフラインで動作し、Web とアプリの台帳は別々です。JSON バックアップ・復元で移行できます。どちらも %APPDATA%/Billing Memo に保存し、ZIP はインストール不要ですが USB 内に台帳を保存する方式ではありません。未署名のため Windows の発行元・SmartScreen 警告が表示される場合があります。SHA-256 を添付しています。

## できること

- サービス名、請求先リンク、プロジェクト、分類、メモをまとめます。クイック追加は名前とリンクのみ入力し、料金を仮定しません。
- 月額・年額・一度のみ・従量制の費用を記録。従量料金は API 自動計測ではなく、**月合計を手入力**します。
- 選択月の支払見込み、支払済み、未払い、定期費用の月換算を表示。支払時に実額を記録できます。
- プロジェクト、分類、検索、カレンダーの日付で絞り込み、サービスの請求画面へ直接移動できます。
- 月間予算、費用内訳、6か月の見込み。USD・KRW・EUR・JPY・CNY・GBP と手動レートに対応。
- JSON バックアップ、月別 CSV、未払いカレンダー（3日前リマインダー）を出力。JSON は検証後、置換を確認して復元します。
- 英語・韓国語・簡体字中国語・日本語・スペイン語、モバイル表示、動きの停止、システムの動き軽減設定に対応。

## 自分の台帳を始める

1. 架空のデモを試し、**自分の台帳を開く**を選びます。デモの編集は一時的で、実際の台帳を上書きしません。
2. サービス、金額、通貨、繰り返しの基準となる**最初の支払日**を追加。最終支払日や未払い見込みの停止も指定できます。
3. 月を選び、**支払いを記録**で実額を入力。ゼロを含め、その請求月の見込み額を置き換えます。
4. 定期的にバックアップ。復元は現在の台帳を置き換えるため、必要なら先に既存データを出力してください。

## 計算ルール

金額は最小通貨単位の整数で保持（KRW・JPY は小数なし、他は2桁）。1月31日の支払いは2月末となり、3月には31日に戻ります。2月29日の年払いは平年では2月28日です。年額は**請求月に全額**計上し、別の月換算指標だけで12分割します。一度のみの支払いは定期費用の月換算に含みません。

支払見込み = 記録済み実額 + 未払い見込み。支払いは予定請求月に属し、実際の支払日は別に保持します。現金主義の会計ソフトではありません。支払済みスナップショットはサービス編集・停止・削除後も保持します。サービス編集は過去分を含む未払い見込みを変更します。1サービスにつき月1請求で、追加取引は別の一度のみ項目を登録してください。

異なる通貨は別集計です。レート未設定は**一部の合計**と表示し、1:1とみなしません。`元通貨1単位 = 表示通貨N単位`を入力し、項目ごとに表示通貨の最小単位に丸めます。表示通貨の変更でレートと予算はリセットされます。リアルタイム為替、将来の使用量・税金・料金変更は予測しません。管理したい総額を入力してください。

## 保存と範囲

ログイン・請求 API・追跡・バックエンドなし。アプリから自動で第三者へリクエストしません。台帳は現在のブラウザーの localStorage に保存し、暗号化せず同一オリジンのスクリプトと共有します。サイトデータの消去で台帳も消え、プライベートモードは一時保存です。分離には専用オリジンでホストしてください。パスワード、API キー、カード番号を保存しないでください。出力ファイルには入力内容が含まれます。

上限は500サービス、5,000支払記録、シリアライズした台帳・取込 JSON は2 MiB、名前80文字、メモ2,000文字、日付2000～2199年です。金額は0以上、項目あたり最小通貨単位で1,000億以下。認証情報を含まない HTTPS リンクのみ対応。複数タブの競合を検出し、保存失敗や破損データには出力・復元方法を提示します。

決済実行、端末同期、請求書照合、バックグラウンド通知は行いません。3日前通知はカレンダーアプリが担当します。出力予定は専用カレンダーに入れると更新・削除が容易です。サービス削除後も支払記録は残り、削除直後には取り消せます。サンプルは架空の金額で、実際の料金表ではありません。

## ローカル実行

Node.js 22.12 以上と npm が必要です。

```sh
git clone https://github.com/jeffrog-256k1/billing-memo.git
cd billing-memo
npm ci
npm run dev
```

表示されたローカル URL を開きます。`dev` は本番 CSP を使う静的アプリをビルドしてプレビューします。ソース変更後は再実行してください。秘密鍵や環境ファイルは不要です。

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run test:reports
npm run format:check
```

ビルド・ブラウザーテスト後、`npm run render:assets` で README 画像を再生成できます。テストは隔離した架空データを使用。Web 版には実行時パッケージ依存がなく、デスクトップ版は Electron を含みます。Vite・TypeScript・Playwright・gifenc は開発用です。
