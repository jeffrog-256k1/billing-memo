# Billing Memo

**모든 도구의 비용을, 하나의 장부로.** 클라우드·호스팅·데이터베이스·메일·API·구독 서비스를 모아 관리하는 브라우저 결제 메모장입니다.

## 주요 기능

- 서비스 이름, 결제 링크, 프로젝트, 분류, 메모를 함께 보관합니다. 빠른 추가는 이름과 링크만 채우며 요금을 임의로 가정하지 않습니다.
- 월간·연간·일회성·사용량 비용을 기록합니다. 사용량은 API 자동 계측이 아닌 **월 합산 금액을 직접 입력**하는 방식입니다.
- 선택한 달의 청구 예상 규모·결제 완료액·남은 예상액·정기 지출 월 환산액을 보여줍니다. 결제 시 실제 금액을 기록할 수 있습니다.
- 프로젝트·분류·검색·캘린더 날짜로 필터링하고 각 서비스의 결제 사이트로 바로 이동합니다.
- 월 예산, 분류별 비용, 6개월 전망을 확인합니다. USD·KRW·EUR·JPY·CNY·GBP와 수동 환율을 지원합니다.
- JSON 백업, 월별 CSV, 미납 결제 캘린더(3일 전 알림)를 내보냅니다. JSON은 검증과 교체 확인 후 복원합니다.
- 영어·한국어·중국어 간체·일본어·스페인어 UI, 모바일 레이아웃, 모션 정지와 시스템 모션 감소 설정을 지원합니다.

## 내 장부 시작하기

1. 가상 데모를 살펴본 뒤 **내 장부 열기**를 누릅니다. 데모 편집은 임시이며 실제 장부를 덮어쓰지 않습니다.
2. 서비스와 금액·통화·**첫 결제 기준일**을 등록합니다. 이 날짜를 기준으로 반복합니다. 마지막 결제일 지정과 미납 예상 일시정지도 가능합니다.
3. 조회 월에서 **결제 기록**을 선택해 실제 금액을 입력합니다. 0원을 포함하여 해당 청구월의 예상액을 대체합니다.
4. 정기적으로 백업합니다. 복원은 현재 장부를 교체하므로 필요하면 기존 장부를 먼저 내보내세요.

## 계산 기준

금액은 최소 통화 단위의 정수로 보관합니다(KRW·JPY 소수점 없음, 나머지 2자리). 1월 31일 결제는 2월 말일, 이후 3월 31일로 이어집니다. 윤년 2월 29일 연간 결제는 평년에 2월 28일로 보정합니다. 연간 비용은 **청구월에 전액** 반영하며 별도 월 환산 지표에만 12로 나눕니다. 일회성 비용은 정기 지출 월 환산에 포함하지 않습니다.

예상 청구 규모 = 완료 실제액 + 미납 예상액입니다. 결제 기록은 예정 청구월에 속하며 실제 납부일은 별도로 보관합니다. 현금주의 회계 프로그램은 아닙니다. 완료 기록은 당시 서비스 정보와 함께 보존하므로 이후 편집·일시정지·제거에 영향을 받지 않습니다. 서비스 편집은 과거를 포함한 미납 예상액을 바꿉니다. 서비스마다 월 1회 청구를 기록하며, 추가 개별 거래는 별도 일회성 항목으로 등록합니다.

통화별 합계는 별도로 유지합니다. 환율이 없으면 **일부 합계**라고 표시하며 1:1로 임의 합산하지 않습니다. `원래 통화 1단위 = 기준 통화 N단위`로 입력하며 항목별로 기준 통화 최소 단위까지 반올림합니다. 기준 통화를 바꾸면 환율·예산이 초기화됩니다. 실시간 환율 갱신, 미래 사용량·세금·서비스 가격 예측은 제공하지 않습니다. 관리할 총금액을 직접 입력하세요.

## 저장과 지원 범위

로그인·결제 API·추적·백엔드 없이 실행되며 자동 외부 요청을 보내지 않습니다. 내 장부는 현재 브라우저의 localStorage에 저장되며 암호화되지 않고 같은 출처의 스크립트와 저장소를 공유합니다. 사이트 데이터를 삭제하면 장부도 지워지고 시크릿 모드는 임시 저장입니다. 분리가 필요하면 독립 출처에 직접 호스팅하세요. 비밀번호·API 키·카드번호는 저장하지 마세요. 내보낸 파일에는 입력 내용이 포함됩니다.

서비스 500개, 결제 기록 5,000개, 직렬화 장부·가져오기 JSON 2MiB, 이름 80자, 메모 2,000자, 날짜 2000~2199년까지 지원합니다. 금액은 0 이상, 항목당 최소 통화 단위 1,000억 이하입니다. 링크는 인증정보가 없는 HTTPS 주소만 허용합니다. 다른 탭의 저장 충돌을 감지하고 저장 실패·손상 데이터에 내보내기와 복구 방법을 제공합니다.

실제 결제 실행, 기기 동기화, 자동 청구서 대조, 백그라운드 알림은 없습니다. 캘린더의 3일 전 알림은 사용하는 캘린더 앱이 처리합니다. 내보낸 일정은 별도 캘린더에 넣으면 갱신·삭제 관리가 편합니다. 서비스 제거 후에도 완료 기록은 남으며 제거 직후 되돌릴 수 있습니다. 샘플 금액은 가상이며 실제 요금표가 아닙니다.

## 로컬 실행

Node.js 22.12 이상과 npm이 필요합니다.

```sh
git clone https://github.com/jeffrog-256k1/billing-memo.git
cd billing-memo
npm ci
npm run dev
```

표시되는 로컬 URL을 엽니다. `dev`는 운영 CSP가 적용된 정적 앱을 빌드하여 미리보기로 실행합니다. 소스 변경 후 다시 실행하세요. 비밀 키나 환경 파일은 필요하지 않습니다.

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
npm run format:check
```

빌드·브라우저 테스트 후 `npm run render:assets`로 README 이미지를 다시 생성할 수 있습니다. 테스트는 격리된 가상 데이터를 사용합니다. 앱 실행 시 외부 패키지 의존성은 없으며 Vite·TypeScript·Playwright·gifenc는 개발 도구입니다.
